# Записка бухгалтеру

Отчёт на дату смотрит, какие деньги к этой дате уже ушли подрядчику (и не вернулись), и раскладывает их по работам.

Строка работы: цена, сколько из выплат уже «закрыло» эту работу, сколько ещё осталось доплатить. Отменённые работы в остатке к оплате = 0.

Платежи без привязки к работе я разнёс по порядку: сначала закрываю принятые работы, потом запланированные. Платёж с указанной работой садится только на неё.

Когда вернётесь, прошу подтвердить три вещи: (1) отменённую съёмку больше не оплачиваем; (2) платёж в очереди и возвращённый аванс в «выплачено» на дату не входят; (3) такой порядок разнесения аванса по работам вас устраивает. Если нет — пересчитаю под ваши правила, суммы по договорам те же, поедут только колонки по работам.
