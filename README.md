# Отчёт по авансам договоров

CLI на Python: по выгрузке договоров, работ и платежей считает на выбранную дату, сколько уже выплачено и сколько осталось — **по каждой работе** и **итогами по договору**.

Задача из жизни бухгалтерии: авансы часто висят на договоре без привязки к работе, а смотреть нужно «за что уже рассчитались».

Контрольная дата из задания: **2026-11-10**.

## Что делает программа

1. Читает три CSV из `data/` (формат — `data/FORMAT.md`).
2. На дату `--date` отбирает платежи, которые к этому дню реально у подрядчика (ушли и не вернулись).
3. Платежи с `work_id` сажает на работу; без привязки — разносит по работам договора.
4. Печатает отчёт в stdout и опционально пишет CSV.

Деньги: `Decimal`, без `float`, до копейки.

## Как читать результат

**Договор:** сумма, обязательства по работам на дату, выплачено, осталось.

**Работа:** `price` / `paid` / `left` и статус на дату (`planned` / `done` / `cancelled`).

Подробности для бухгалтера — `ACCOUNTANT.md`.  
Спорные правила — `DECISIONS.md`.

Кратко:

- `queued` не в «выплачено»; `refunded` после даты возврата = 0
- отменённая работа: остаток 0
- аванс без `work_id`: сначала принятые (по дате приёмки), потом planned

## Примеры на разные даты

Контрольная из задания — **2026-11-10**. Ниже ещё два среза, чтобы было видно, как ведут себя возврат, очередь и поздний платёж.

### 2026-11-10 (контроль)

```bash
PYTHONPATH=src python3 -m advance_report --date 2026-11-10 --data data
```

| Договор | Выплачено | Осталось |
|---------|-----------|----------|
| D-1 Студия «Свет» | 315 000.00 | 185 000.00 |
| D-2 Иван Петров | 75 000.00 | 15 000.00 |

Что важно: P-2 уже возвращён → в выплачено не входит; P-4 в очереди → тоже нет; P-8 от 12.11 ещё не был; W-23 на эту дату ещё `planned`. Пример CSV: `out/report-2026-11-10.csv`.

### 2026-09-05 (до возврата ошибочного аванса)

```bash
PYTHONPATH=src python3 -m advance_report --date 2026-09-05 --data data
```

| Договор | Выплачено | Осталось |
|---------|-----------|----------|
| D-1 | 350 000.00 | 250 000.00 |
| D-2 | 0.00 | 90 000.00 |

На D-1 ещё «висит» ошибочные 50 000 (P-2 вернут только 10.09). Все работы D-1 пока `planned`, обязательства 600 000. Пример: `out/report-2026-09-05.csv`.

### 2026-11-15 (после P-8 и приёмки W-23)

```bash
PYTHONPATH=src python3 -m advance_report --date 2026-11-15 --data data
```

| Договор | Выплачено | Осталось |
|---------|-----------|----------|
| D-1 | 315 000.00 | 185 000.00 |
| D-2 | 95 000.00 | 0.00 |

W-23 уже `done`, P-8 вошёл в выплачено. По D-2 выплачено 95 000 при обязательствах 90 000 — лишние 5 000 видны как surplus по договору (доплаты сверх цен работ). Пример: `out/report-2026-11-15.csv`.
