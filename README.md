# Отчёт по авансам договоров

CLI на Python: по выгрузке договоров, работ и платежей считает на выбранную дату, сколько уже выплачено и сколько осталось — **по каждой работе** и **итогами по договору**.

Задача из жизни бухгалтерии: авансы часто висят на договоре без привязки к работе, а смотреть нужно «за что уже рассчитались».

Контрольная дата из задания: **2026-11-10**.

Python 3.10+. Внешних зависимостей для запуска нет.

```bash

cd advance-report-candidate-B

```

## Что делает программа

1. Читает три CSV из `data/` (формат — `data/FORMAT.md`).
2. На дату `--date` отбирает платежи, которые к этому дню реально у подрядчика (ушли и не вернулись).
3. Платежи с `work_id` сажает на работу; без привязки — разносит по работам договора.
4. Печатает отчёт в stdout и опционально пишет CSV.

Деньги: `Decimal`, без `float`, до копейки.

## Как читать результат

**Договор:** сумма, обязательства по работам на дату, выплачено, осталось.

**Работа:** `price` / `paid` / `left` и статус на дату (`planned` / `done` / `cancelled`).

Подробности для бухгалтера — `ACCOUNTANT.md`.  
Спорные правила — `DECISIONS.md`.

Кратко:

- `queued` не в «выплачено»; `refunded` после даты возврата = 0
- отменённая работа: остаток 0
- аванс без `work_id`: сначала принятые (по дате приёмки), потом planned
