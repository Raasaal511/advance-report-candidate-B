# Сессия работы (Cursor / Composer)

Это не подмена Claude Code `/export`, а лог того, как собиралось решение.

## Задача

Отчёт на дату: по работам (цена / выплачено / осталось) и итоги по договорам. Данные только из `data/`. Деньги без float. DECISIONS.md + записка бухгалтеру.

## Ход

1. Разобрал CSV и FORMAT.md. Зафиксировал развилки: статус на дату, queued/refunded, отмена работы, разнесение аванса без `work_id`.
2. Собрал CLI: Decimal, effective paid на дату, FIFO-разнесение (сначала done, потом planned).
3. Проверил контрольную дату 2026-11-10: D-1 315000/185000, D-2 75000/15000.
4. Разложил монолит в пакет `src/advance_report/` (loaders / calc / formatters / cli), добавил unittest и README.
5. Добавил альтернативные срезы 2026-09-05 и 2026-11-15 в README и тесты; артефакты в `out/`.
